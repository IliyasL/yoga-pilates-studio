# Yoga and Pilates Studio - Landing Page

ICT6001 Week 9 project: a responsive landing page for a yoga and pilates studio.

- Pure HTML5 + CSS3 (Grid, Flexbox, custom properties), no JavaScript, no frameworks
- Mobile-first, `@media (min-width: 1024px)` for desktop
- Burger menu, form validation and the dark-mode switch are made with CSS only
- Layout designed in Figma (1440 px and 390 px frames, Light and Dark themes)

Live site: GitHub Pages (Settings -> Pages -> Deploy from branch `main`, folder `/ (root)`).
